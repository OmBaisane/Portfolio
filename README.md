## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/OmBaisane/Portfolio.git
```

Navigate to the project

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
